Frequently asked questions

CodeTrack basics
What is CodeTrack used for?

CodeTrack helps teachers create coding exercises, collect multiple student submissions, review each attempt, and track progress over time.

Can students submit more than once for the same exercise?

Yes. Every attempt is stored separately so teachers can review the full history and students can see how their work improves.

How does teacher feedback work?

Teachers can change submission status, add review comments, and keep that feedback attached to the exact attempt it belongs to.

Can students see their improvement?

Yes. The progress area shows attempt history, scores, and the latest review notes so students can understand how their performance changes over time.

Does the platform store data after refresh?

Yes. The current version uses a Node.js and Express backend connected to MongoDB Atlas, so exercises, submissions, reviews, and comments remain available after refresh and across deployments.

Who is this platform for?

It works well for coding bootcamps, colleges, internal training teams, and any instructor-led programming environment.
