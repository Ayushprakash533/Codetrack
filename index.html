How it works

How CodeTrack works

  • Teachers publish coding tasks with requirements, difficulty, and optional starter resources.
  • Students submit one or more attempts for the same exercise as they improve their solution.
  • Teacher feedback stays attached to the correct submission, making reviews easy to follow.
  • The progress tracker shows score changes, statuses, and comments over time.
  • All core records are loaded from an Atlas-backed API so exercises, submissions, reviews, and comments stay available in the cloud.
