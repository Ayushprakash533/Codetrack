About CodeTrack

CodeTrack helps teachers run coding practice with structure and clarity.

The platform is designed for instructor-led coding programs that need clear exercises, repeatable review workflows, and visible student improvement over time.

Turn submission data into real learning progress

CodeTrack is built around a simple cycle: assign work, collect attempts, review carefully, and help students improve with clearer feedback.

What We Focus On

CodeTrack focuses on the full teaching loop: assign, submit, review, revise, and track progress with less friction.

Clear exercise publishing

Teachers can create structured coding tasks with language, difficulty, prompts, and starter links in one place.

Multiple submissions per task

Students are not limited to one attempt. Every submission is stored so improvement is visible instead of hidden.

Actionable review flow

Feedback is tied directly to each attempt so students can understand what changed and what still needs work.

Progress students can see

Attempt history, scores, and review comments create a timeline that makes growth measurable.

Cloud-backed delivery

The platform uses MongoDB Atlas for persistent data and can be deployed on Vercel with the same API structure.
